# 📊 AI Data Analyst Agent

An AI-powered data analysis tool that allows users to upload datasets and generate insights using Large Language Models (LLMs).

---

## 🚀 Features

* Upload CSV datasets
* Preview dataset
* Generate basic statistics
* Automatic data visualization
* Ask questions about data
* AI-generated insights

---

## ⚙️ Tech Stack

* Python
* Streamlit
* Pandas
* OpenAI API
* Matplotlib

---

## 🎯 Use Cases

* Business data analysis
* Exploratory data analysis
* Insight generation
* Decision support
